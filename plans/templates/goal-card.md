# Goal Card Template

Use this for serious Codex `/goal` runs. A goal is a bounded mission, not open-ended autonomy.

## Objective

One concrete outcome that should be true when the goal is complete.

## Repo

Absolute repo path and branch or worktree.

## Owner

Keith or named session owner.

## Allowed Workers

List the allowed agents or tools. Say which one may edit files.

## Scope Boundaries

Files, systems, or behaviors that are in scope.

Files, systems, or behaviors that are explicitly out of scope.

## Binary Done Checks

Commands, screenshots, user-visible behaviors, or exact artifacts that prove completion.

## Verification Commands

Commands to run before declaring success.

## Review Gate

Who reviews the work, using which command, and which builder-family applies.

## Stop-If Conditions

Conditions that force the goal to stop and ask Keith instead of continuing.
