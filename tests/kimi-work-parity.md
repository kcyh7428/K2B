# Codex and Kimi Work parity acceptance

The separate phone service, personal cloud export, automatic Kimi history
capture and new schedules are deferred. This checklist never authorizes live
checkout activation, commit, push or changes to the two native memory jobs.

## Supported entry

Open the same local K2B folder as the project in Kimi Work. Its current
AGENTS.md instructs Kimi to run scripts/k2b-bootstrap.py on fresh entry. This
uses the same source-labelled renderer as Codex SessionStart. It does not
register or emulate a Kimi startup hook or install a second skill tree.

Kimi documents project-folder access and persistent AGENTS.md instructions:
https://www.kimi.ai/academy/kimi-work-getting-started (accessed 24 October 2026).
Installed app behavior must still be tested; product documentation is not an
execution receipt. Never use the Code CLI as evidence of a Work conversation.

## Test matrix

Run fictional checks in a temporary vault with private state, never the real
vault. Preserve source hashes, exact commands, writer receipts and assistant
results. Restrict each assistant to the fixture and existing public sources.

| Check | Required observable behavior |
|---|---|
| Startup on Home and SJM | Actual AGENTS.md and renderer reads; same local rules and profile; local status and unverified synchronization remain separate |
| Home unavailable | SJM uses local files without contacting Home; shared reconciliation remains waiting or unverified |
| Corrected project recall | Fresh conversation cites the latest fictional decision and distinguishes the earlier decision |
| Running-only query | Read selected running note; exclude unrelated recruiting evidence; a broad partial packet requires narrowing |
| Public research | Actual source-tool retrieval and citations, or precise unavailable-tool fallback; no paid API fallback |
| Company drafting | Local fictional company source read before drafting; no implicit mailbox operation; circulation draft check |
| Ordinary save | Actual expected-hash writer receipt, local index update and fresh-reader recall; stale hash and conflict preserve prior content |
| Missing tools/profile | Clear limitation or stale-source label, no fabricated successful startup or save |

## Delivery states

Automated helper tests prove local execution, not assistant behavior. Record
fresh Codex and Kimi Work runs separately for each Mac. Home-off tests must
distinguish an isolated no-network fixture from a physically disconnected
Home. Do not claim either Mac activated until the reviewed code is deliberately
delivered and its project entry verified. Keep SJM adaptations unchanged.
